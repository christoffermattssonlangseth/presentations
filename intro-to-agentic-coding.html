Introduction 04 / 26
Background 03
What is it?

What is agentic
coding?

  • Also called vibe coding, prompt engineering, AI-assisted development
  • Autonomous AI agents (LLMs) that can write, read, and execute code
  • Levels of use:
  • Low — Ask ChatGPT or Claude to write code snippets for you
  • High — Agents like Codex and Claude Code get full filesystem access: read, write, execute

Introduction 07 / 26
Guidance 06
Working effectively

General
best practices

  • They understand natural language — write to them like you would any engineer
  • Learn the "language" of the agent over time
  • Images work well for providing visual context
  • Context is everything — but too much can also hurt performance
  • Use both tools together: have one write, the other review
Introduction 08 / 26
Context 07
Memory & context windows

A note on
context

  • Context is essentially the agent's working memory
  • It is limited — agents compact their memory when full
  • Compaction: reducing context size while preserving key information
  • Too much or too little context and the agent struggles — there's a sweet spot
  • Recommended: compact at around 70–90% context usage

Useful
Features

Tools and capabilities that make agents more reliable and consistent.

Useful Features 10 / 26
Configuration 09
Project control files

AGENTS.md
/ CLAUDE.md

  • A control file that tells coding agents how to behave in your project
  • Makes output consistent, predictable, and aligned with your conventions
  • Defines: project context, rules, coding patterns, workflows, known pitfalls
  • Prevents agents from making generic or wrong assumptions
  • A long-term "operating manual" for agents — vs. prompts which are short-term
Useful Features 11 / 26
Extensibility 11
Modular capabilities

Agentic
Skills

  • Skills extend AI agents with specialized knowledge and workflows
  • A skill is a folder with a SKILL.md file at its core
  • Can also include scripts, templates, and reference materials
  • Modular, reusable, and easy to share across projects and teams
  • This presentation was built using the frontend-slides skill
Useful Features 12 / 26
Coordination patterns

Multi-Agent
Workflows

Codex
  • Parallel agents / subagents — run tasks simultaneously, aggregate results
  • Custom agents with different models and instructions
  • Best for highly parallel tasks: exploration, multi-step builds
  • Watch-out: context pollution / rot
Claude Code
  • Sub-agents with roles coordinated by a main agent
  • Planner → delegates → aggregates
  • Strong for structured, multi-step workflows
Key difference
Codex — parallel execution
Claude Code — hierarchical delegation

The different interfaces for working with coding agents.

Interaction 14 / 26
Interface 14
Terminal

Command Line
Interface (CLI)

  • Most powerful interface — full control via the terminal
  • Feels similar to a chatbot, but with direct filesystem access
  • Can feel daunting at first, very powerful once familiar
  • Use cmux to run multiple windows and agent instances in a single view
  • Enables parallel agent workflows in one terminal layout

Are people actually using agentic coding? Four developers share their views.

Perspectives 21 / 26
Developer Perspective · 1 of 4

Rust Developer

Stockholm-based hardware company

  • Agentic coding is still niche — mostly used by AI researchers, not mainstream engineering
  • Useful for autocomplete and boilerplate, but not reliable for production systems
  • Trust is limited — not yet ready to build robust systems independently
  • Developer performance should be judged by output, not the tools used
  • Worth using while it's cheap, but avoid deep dependency long-term
Perspectives 22 / 26
Developer Perspective · 2 of 4

Computational Biologist & Biostatistician

 

  • LLMs are now essential for coding — not using them means falling behind
  • Massively increase speed and productivity, especially for prototyping
  • Most impactful on new projects — less so on large, legacy codebases
  • Industry pressure is shifting expectations — AI-assisted coding is becoming the norm
  • Coding is shifting from craft → throughput and iteration speed

Computational Biologist

Engineering Manager

Weighing the upsides and downsides of agentic coding.

Conclusion 27 / 28
Taking stock

Upsides & Downsides

Upsides
  • Shifts you from worker to architect
  • Makes coding idea-driven — anyone with great ideas can build great things
  • Significant increase in productivity and iteration speed
Downsides
  • Risk of losing deep technical understanding
  • Inconsistent code quality
  • Over-reliance risk
  • Security & safety concerns
Conclusion 28 / 28
Concerns 28
Looking further ahead

Agentic Coding —
Broader Concerns

  • Longevity & dependence — What happens if these tools change, degrade, or disappear? Risk of over-reliance
  • Environmental impact — Increasing compute demands → energy use and carbon footprint
  • Data privacy & governance — Sending code/data to external providers → security, confidentiality, compliance
  • Ethical considerations — Use of AI by large companies (e.g. defense collaborations) raises values and alignment questions
