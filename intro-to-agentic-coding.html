Part One

Introduction

What is agentic coding, and who are the key players?

Introduction
Background
What is it?

What is agentic coding?

  • Also called vibe coding, prompt engineering, AI-assisted development
  • Autonomous AI agents (LLMs) that can write, read, and execute code
  • Levels of use:
  • Low — Ask ChatGPT or Claude to write code snippets for you
  • High — Agents like Codex and Claude Code get full filesystem access: read, write, execute
Introduction
Tools
OpenAI

Introduction to Codex

  • OpenAI's coding agent
  • Latest generation (gpt-5.4) works very well
  • Model range: gpt-5.4, gpt-5.4-mini, gpt-5.3-codex, gpt-5.2-codex
  • Available as desktop app, CLI, and VS Code extension
Introduction
Tools
Anthropic

Introduction to Claude Code

  • Anthropic's coding agent — had an early edge on the field
  • Codex is accelerating and closing the gap
  • Three model tiers:
  • Opus 4.6 — Most intelligent
  • Sonnet 4.6 — Speed + intelligence balance
  • Haiku 4.5 — Fastest
  • Available as desktop app, CLI, and VS Code extension
Introduction
Personal experience

My take: Codex vs Claude Code

Claude Code
  • Better at one-shotting things — tends to get it right on the first try
  • Really strong at design decisions — often nails it where Codex is unreliable
Codex
  • Often takes a long time to think before responding
  • I find myself trusting its output more — not entirely sure why
  • Much more permissive with token limits — Claude tokens run out fast
Bottom line
It's not one vs the other — they complement each other
Introduction
Guidance
Working effectively

General best practices

  • They understand natural language — write to them like you would any engineer
  • Learn the "language" of the agent over time
  • Images work well for providing visual context
  • Context is everything — but too much can also hurt performance
  • Use both tools together: have one write, the other review
Introduction
Context
Memory & context windows

A note on context

  • Context is essentially the agent's working memory
  • It is limited — agents compact their memory when full
  • Compaction: reducing context size while preserving key information
  • Too much or too little context and the agent struggles — there's a sweet spot
  • Recommended: compact at around 70–90% context usage

Part Two

Useful Features

Tools and capabilities that make agents more reliable and consistent.

Useful Features
Configuration
Project control files

AGENTS.md / CLAUDE.md

  • A control file that tells coding agents how to behave in your project
  • Makes output consistent, predictable, and aligned with your conventions
  • Defines: project context, rules, coding patterns, workflows, known pitfalls
  • Prevents agents from making generic or wrong assumptions
  • A long-term "operating manual" for agents — vs. prompts which are short-term
Useful Features
Extensibility
Modular capabilities

Agentic Skills

  • Skills extend AI agents with specialized knowledge and workflows
  • A skill is a folder with a SKILL.md file at its core
  • Can also include scripts, templates, and reference materials
  • Modular, reusable, and easy to share across projects and teams
  • This presentation was built using the frontend-slides skill

Useful Features
Coordination patterns

Multi-Agent Workflows

Codex
  • Parallel agents / subagents — run tasks simultaneously, aggregate results
  • Custom agents with different models and instructions
  • Best for highly parallel tasks: exploration, multi-step builds
  • Watch-out: context pollution / rot
Claude Code
  • Sub-agents with roles coordinated by a main agent
  • Planner → delegates → aggregates
  • Strong for structured, multi-step workflows
Key difference
Codex — parallel execution
Claude Code — hierarchical delegation

How to Interact

The different interfaces for working with coding agents.

Interaction
Interface
Terminal

Command Line Interface (CLI)

  • Most powerful interface — full control via the terminal
  • Feels similar to a chatbot, but with direct filesystem access
  • Can feel daunting at first, very powerful once familiar
  • Use cmux to run multiple windows and agent instances in a single view
  • Enables parallel agent workflows in one terminal layout

Real Perspectives

Are people actually using agentic coding? Five developers share their views.

Perspectives
Developer Perspective · 1 of 5

Rust Developer

Stockholm-based hardware company

  • Agentic coding is still niche — mostly used by AI researchers, not mainstream engineering
  • Useful for autocomplete and boilerplate, but not reliable for production systems
  • Trust is limited — not yet ready to build robust systems independently
  • Developer performance should be judged by output, not the tools used
  • Worth using while it's cheap, but avoid deep dependency long-term
Perspectives
Developer Perspective · 2 of 5

Computational Biologist & Biostatistician

 

  • LLMs are now essential for coding — not using them means falling behind
  • Massively increase speed and productivity, especially for prototyping
  • Most impactful on new projects — less so on large, legacy codebases
  • Industry pressure is shifting expectations — AI-assisted coding is becoming the norm
  • Coding is shifting from craft → throughput and iteration speed
Perspectives
Developer Perspective · 3 of 5

Computational Biologist

Stockholm-based biotech startup

  • Limited experience with agentic coding — interesting concept, untested in practice
  • Already requires double-checking outputs from current AI tools
  • Unclear if agents actually reduce workload or just shift it
  • Verification overhead may offset the productivity benefits
  • Open to trying it, but waiting for clearer evidence of value
Perspectives
Developer Perspective · 4 of 5

Engineering Manager

Software company

  • Moving toward not writing code manually at all — agents handle execution
  • Potential to build ~10× more through parallelization and automation
  • Work shifts to planning, decision-making, and evaluation
  • Orchestrating multiple agents in parallel instead of working serially
  • Strong belief this will fundamentally reshape how software is built
Perspectives
Developer Perspective · 5 of 5

Java Programmer

Security industry

  • This is a "prime moment" to use AI tools — models are likely priced below their true cost
  • Strong incentive to exploit the upside now, while avoiding dependence
  • Use heavily, but don't become reliant on a single provider
  • Treat as a temporary advantage, not guaranteed long-term infrastructure

Recent Developments

The field is moving fast

What's happening right now

OpenAI
DoD collaboration drives users to Anthropic

OpenAI's partnership with the US Department of Defense raised ethical concerns among researchers and developers, prompting a visible shift toward Anthropic as a perceived safer alternative.

Anthropic
Tighter token limits push users away

Anthropic's introduction of more restrictive token limits has frustrated power users, particularly in long research sessions — sending some back toward Codex, which remains more permissive.

Security
Claude Code source code leaked

Leaked via a map file in their npm registry. Codex could adopt ideas from it, and open-source Claude Code clones may soon emerge.

Operon is a new Anthropic product built for scientific research — with native capabilities for biology workflows and single-cell analysis, targeted directly at the research community.

Part Seven

Where does this leave us?

Weighing the upsides and downsides of agentic coding.

Conclusion
Taking stock

Upsides & Downsides

Upsides
  • Shifts you from worker to architect
  • Makes coding idea-driven — anyone with great ideas can build great things
  • Significant increase in productivity and iteration speed
Downsides
  • Risk of losing deep technical understanding
  • Inconsistent code quality
  • Over-reliance risk
  • Security & safety concerns
Conclusion
Concerns
Looking further ahead

Broader Concerns

Longevity & dependence What happens if these tools change, degrade, or disappear? Risk of over-reliance on external infrastructure.
Environmental impact Increasing compute demands → growing energy use and carbon footprint.
Data privacy & governance Sending code and data to external providers raises security, confidentiality, and compliance concerns.
Ethical considerations Use of AI by large companies — e.g. defense collaborations — raises values and alignment questions.
